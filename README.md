## 🚀 Featured Project

### 🎬 Book My Ticket — Movie Ticket Booking System

A full-stack movie ticket booking application built using Java and Spring Boot, featuring movie browsing, seat selection, ticket booking, and separate user and admin workflows.

**Tech Stack:** Java 17, Spring Boot, Spring MVC, Thymeleaf, Spring Data JPA, Hibernate, MySQL, Redis.
